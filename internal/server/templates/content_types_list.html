Los campos de un tipo se pueden editar: agregar uno nuevo (queda vacío en el contenido que ya existe) o renombrar uno existente (conserva sus datos). Quitar un campo BORRA sus datos y pide confirmación. El tipo de un campo no se puede cambiar. «Borrar» elimina el tipo entero —definición, campos y su tabla con todas sus filas— y te muestra cuántas filas se van a destruir antes de pedirte la confirmación.

Una relación es una clave foránea real hacia otro tipo dinámico y se declara al crear el tipo. Mientras exista, el tipo DESTINO no se puede editar ni borrar: para liberarlo hay que borrar el tipo que lo referencia.
